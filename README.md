# loto-calendario-privacy
* Informativa sulla Privacy

* Ultimo aggiornamento: 5 ottobre 2026

* La presente informativa, descrive le modalità di gestione dell'applicazione LotoCalendario, in merito alla privacy e ai dati degli utenti.

1. Raccolta dei dati personali:

   L'applicazione non raccoglie, non memorizza, non registra, non trasmette alcun dato
   personale dell'utente verso server esterni, cloud di terze parti o soggetti esterni.
   
2. Gestione dei dati locali ( Memoria Interna ):

   L'applicazione memorizza le informazioni riguardanti gli incarichi, appuntamenti
   o altro, per mano dell'utente stesso in area di memoria interna, del dispositivo,
   nella directory interna dove e' stata installata la applicazione stessa, e all'esterno
   di suddetta directory sempre e comunque nella memoria del dispositivo, o in unita
   Flash drive usb o altro, collegate al dispositivo, con il suo File Manager, per mano
   del utente e solo per suo volere o desiderio di importare, i contenuti da lui salvati
   all'esterno.
   
3. Sicurezza:
   
   Poiché gli incarichi creati dall'utente, sono salvati internamente nella directory di
   installazione della applicazione, nella directory di default preposta, la sicurezza di
   ciò che viene inserito dall'utente stesso, e' di livello medio alto perché protetto dal
   sistema operativo.
